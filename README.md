# 📚 Book App Cool

An interactive web application for browsing and managing books, built as a collaborative pair-programming project for our Frontend Web Development Bootcamp. This project was developed using professional workflows including **Git Flow** and a component-based architecture in **React**.

---

## 🛠️ Tech Stack

- **Framework / UI:** [React](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Tooling & Bundler:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Version Control:** Git & GitHub (Git Flow)

---

## 🚀 Key Features

- 🔍 **Search & Explore:** Interactive book catalog navigation.
- 🎨 **Responsive Design:** Modern and adaptable UI across mobile and desktop devices using Tailwind CSS.
- ⚡ **Ultra-Fast Performance:** Bundled and served through Vite.
- 🛡️ **Type Safety:** Robust codebase powered by TypeScript.

---

## 👥 Team Workflow (Git Flow)

To simulate a professional team environment, we followed the **Git Flow** branching strategy:

1. **`main`**: Protected branch reserved exclusively for stable production releases.
2. **`develop`**: Primary integration branch where all completed features were merged.
3. **`feature/*`**: Each developer worked on isolated tasks in separate feature branches (`feature/navbar`, `feature/styles`, `feature/routes`, etc.).
4. **Pull Requests & Code Review:** Every feature was merged into `develop` through Pull Requests reviewed and approved by the peer collaborator.

## 💻 Getting Started

Follow these steps to clone and run the project on your local machine:

### 1. Clone the repository
```bash
git clone [https://github.com/Joel-Gandalf/book_app_cool.git](https://github.com/Joel-Gandalf/book_app_cool.git)
cd frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open your browser and navigate to the local URL shown in the terminal (typically http://localhost:5173).

## 📦 Available Scripts
In the project directory, you can run:

npm run dev: Starts the development server with live reload.

npm run build: Compiles the application for production in the dist folder.

npm run preview: Previews the production build locally.

npm run lint: Runs the linter to inspect code quality.
